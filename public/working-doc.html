2. Top 3 Research Findings & Why They Matter

  1. Nearly 1 in 4 aggregated listings (23.8% — 93 of 390 raw posts) are cross-board duplicates or tracking-URL clones: Collected across 20 official public Greenhouse India career boards, Remotive Public API, Jobicy Public API, and HN Algolia API. Removing duplicates across Canonical URL (22), Normalized SHA-256 Entity Hash (53), and Fuzzy Similarity ≥ 84% (18) before calling Gemini cuts LLM costs by ~24% and prevents feed spam.
  2. Indian neighborhood names and boilerplate HQ addresses break naive city filters: Startups regularly list sub-localities (Baner, Hinjewadi Phase 2, Borivali, Andheri, Koramangala, Gurugram) or mention HQ addresses inside job descriptions. Enforcing strict priority on location_raw and mapping 150+ neighborhoods + International / Global raised city normalization accuracy to 96.0% (48/50).
  3. Public ATS feeds leak Senior roles, and early-stage startups need direct applicant contacts: Filtering Senior/Staff/Principal/Manager roles pre-AI keeps the feed 100% fresher-focused, compact 10-job batching on Gemini 3.1 Flash-Lite reduces paid tagging cost to Rs. 8.94 ($0.095) per 1,000 posts (Rs. 4.47 via Batch API; Rs. 0 on Free Tier), and optional external URLs + Direct Apply + live scroll injection let startups without websites hire immediately.

5. Exact Prompts Used in Production

Prompt A — Single-Job Preview & Reasoning (tagger/tag_jobs.py → SYSTEM_PROMPT)

You are Beep's Senior Career Taxonomy LLM.
Given a batch of Indian fresher / college internship job postings, classify each job into:
1. role_tag: MUST be one of 14 canonical roles (Software Engineering, Frontend & Web Dev, Backend & Cloud/DevOps, Data Science & AI/ML, Mobile Development, Product Design (UI/UX), Product Management, Marketing & Growth, Business Development & Sales, Operations & Strategy, Content & Social Media, Finance & Analyst, HR & Talent, QA & Testing).
2. city: MUST normalize to one of 15 locations (Bengaluru, Pune, Mumbai, Hyderabad, Delhi NCR, Chennai, Kolkata, Ahmedabad, Jaipur, Kochi, Indore, Chandigarh, Remote (India), Pan-India / Multiple, International / Global).
   - Map Bangalore/BLR/HSR/Koramangala/Whitefield -> Bengaluru
   - Map Baner/Hinjewadi/Kharadi/Viman Nagar/Wakad/Balewadi -> Pune
   - Map Gurgaon/Gurugram/Noida/New Delhi/Faridabad -> Delhi NCR
   - Map Bombay/Powai/Andheri/Borivali/BKC/Thane/Navi Mumbai -> Mumbai
   - Map HITEC City/Gachibowli/Madhapur/Secunderabad -> Hyderabad
   - Map OMR/Guindy/Taramani -> Chennai
   - Map Work From Home/WFH/Anywhere -> Remote (India)
   - Always prioritize location_raw over description boilerplate.
3. confidence (0.75-0.99), is_fresher (boolean), reasoning (1 sentence). Return ONLY valid JSON.

Prompt B — Compact 10-Job Batch Prompt (tagger/tag_jobs.py → call_gemini_batch)

Tag Indian fresher/internship jobs into role_tag and city. Map Baner/Hinjewadi->Pune, Borivali/Andheri/Powai->Mumbai, HSR/Koramangala->Bengaluru, Gurugram/Noida->Delhi NCR. Return JSON array of {id, role_tag, city, confidence} only.

Prompt C — Express Single-Job Fallback Prompt (server/index.ts → callPythonSingleTagger)

Classify this Indian fresher/internship job into role_tag (14 canonical roles) and city (15 canonical locations). Always prioritize location_raw over description when determining city (e.g. Borivali/Andheri/Powai -> Mumbai, Baner/Hinjewadi -> Pune, Koramangala/HSR -> Bengaluru). Return JSON with keys role_tag, city, confidence, reasoning.

7. Key Engineering Challenges Resolved

  1. Zero-Refresh Real-Time Student Feed: Server-Sent Events (/api/stream) + cross-tab localStorage listeners display a clickable toast and smoothly inject newly published recruiter jobs as students scroll down — preserving scroll position without a refresh.
  2. Location Field Priority & 150+ Neighborhood Aliases: Fixed cases where description boilerplate (e.g., a Pune HQ address) overrode explicit Mumbai suburbs (Borivali, Andheri) and added International / Global mapping.
  3. Gemini Model Upgrade & Token Cost Optimization: Migrated from deprecated 2.5-flash-lite to gemini-3.1-flash-lite with compact 10-job JSON batches, verified live at 98 input + 47 output tokens/job (Rs. 8.94 standard / Rs. 4.47 Batch API per 1,000 jobs).
  4. Serverless Deployment & Strict Fresher Guardrails: Bundled static JSON configs/data into Vercel via static TS imports + vercel.json rewrites, enforced Senior/Manager title rejection pre-AI and on submit, and passed 13/13 automated tests (npm test).
