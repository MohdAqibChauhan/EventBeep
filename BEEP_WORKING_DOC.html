2. Top 3 Research Findings & Why They Matter

  1. 23.8% of raw aggregated listings (93 of 390) are cross-board duplicates or tracking-URL clones: Collected across 20 Greenhouse India boards, Remotive API, Jobicy API, and HN Algolia API. Removing duplicates across Canonical URL (22), Normalized SHA-256 Entity Hash (53), and Fuzzy Similarity >= 84% (18) before calling Gemini cuts LLM costs by ~24%.
  2. Indian neighborhood names and boilerplate HQ addresses break naive city filters: Startups list micro-localities (Baner, Hinjewadi Phase 2, Borivali, Andheri, Koramangala, Gurugram) or HQ addresses in descriptions. Prioritizing location_raw and mapping 150+ sub-localities + International / Global lifted city accuracy to 96.0% (48/50).
  3. ATS feeds leak Senior roles, and startups without websites need direct applicant contact: Filtering Senior/Principal/Manager roles pre-AI keeps the feed 100% fresher-focused, compact 10-job batching on Gemini 3.1 Flash-Lite lowers paid cost to Rs. 8.94 ($0.095) per 1,000 posts (or Rs. 4.47 via Batch API), and Direct Apply + live scroll injection lets startups collect student contacts immediately.

4. AI Tools & Tech Stack

  • AI / LLM Tagging: Google Gemini 3.1 Flash-Lite (gemini-3.1-flash-lite, responseMimeType: "application/json", temperature 0.1), Python 3 worker (tagger/tag_jobs.py), config/taxonomy.json (150+ neighborhood aliases).
  • Backend: Node.js, TypeScript, Express.js, JWT + bcryptjs, node-cron (daily 06:00 AM IST sync), Cheerio, Server-Sent Events (/api/stream).
  • Frontend: HTML5, CSS3, Vanilla JS (ES2022) with SSE + localStorage scroll-triggered card injection and reload persistence.
  • Database & Hosting: PostgreSQL schema + Dual-Sync JSON store, Vercel Serverless + GitHub. Automated tests: 13/13 passing (npm test).

5. Exact AI Prompts Used

Prompt A — Full Single-Job Taxonomy Prompt (tagger/tag_jobs.py)

You are Beep's Senior Career Taxonomy LLM.
Given a batch of Indian fresher / college internship job postings, classify each job into:
1. role_tag: MUST be one of 14 canonical roles (Software Engineering, Frontend & Web Dev, Backend & Cloud/DevOps, Data Science & AI/ML, Mobile Development, Product Design (UI/UX), Product Management, Marketing & Growth, Business Development & Sales, Operations & Strategy, Content & Social Media, Finance & Analyst, HR & Talent, QA & Testing).
2. city: MUST normalize to one of 15 locations (Bengaluru, Pune, Mumbai, Hyderabad, Delhi NCR, Chennai, Kolkata, Ahmedabad, Jaipur, Kochi, Indore, Chandigarh, Remote (India), Pan-India / Multiple, International / Global).
   - Map Bangalore/BLR/HSR/Koramangala/Whitefield -> Bengaluru
   - Map Baner/Hinjewadi/Kharadi/Viman Nagar/Wakad/Balewadi -> Pune
   - Map Gurgaon/Gurugram/Noida/New Delhi/Faridabad -> Delhi NCR
   - Map Bombay/Powai/Andheri/Borivali/BKC/Thane/Navi Mumbai -> Mumbai
   - Map HITEC City/Gachibowli/Madhapur/Secunderabad -> Hyderabad
   - Map OMR/Guindy/Taramani -> Chennai
   - Map Work From Home/WFH/Anywhere -> Remote (India)
   - Always prioritize location_raw over description boilerplate.
3. confidence (0.75-0.99), is_fresher (boolean), reasoning (1 sentence). Return ONLY valid JSON.

Prompt B — Compact 10-Job Batch Prompt (Bulk Sync Optimization)

Tag Indian fresher/internship jobs into role_tag and city. Map Baner/Hinjewadi->Pune, Borivali/Andheri/Powai->Mumbai, HSR/Koramangala->Bengaluru, Gurugram/Noida->Delhi NCR. Return JSON array of {id, role_tag, city, confidence} only.
